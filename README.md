# Backend Development – Bridge Lab

This repository is created as part of our college Bridge Lab to systematically learn and implement backend development concepts.

It is organized using a **topic-wise branch structure**, where each branch focuses on a specific concept and contains related tasks, implementations, and exercises.

---

## 📌 Repository Structure

Instead of storing everything in a single branch, this repository follows a **modular learning approach**:

Each topic is maintained in a separate branch:

* `unix-commands`
* `git-github`
* `nodejs-programming`
* `file-system-operations`
* `express-framework`
* `restful-apis-routing`
* `introduction-to-databases`
* `middleware-express-session-cookies`
* `authentication-authorization`
* `rest-security`
* `deployment`

---

## 🎯 Objective

The goal of this repository is to:

* Build a strong foundation in backend development
* Practice real-world concepts step-by-step
* Understand how different backend components integrate
* Prepare for internships and industry-level development

---

## 🛠️ Tech Stack

* Node.js
* Express.js
* MongoDB 
* Git & GitHub

## 📚 How to Use This Repository

1. Clone the repository:

   ```bash
   git clone <your-repo-link>
   ```

2. Switch to a specific branch:

   ```bash
   git checkout <branch-name>
   ```

3. Explore tasks and implementations inside that branch.
